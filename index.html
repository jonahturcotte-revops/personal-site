About

I've spent my career inside revenue operations for B2B software companies — architecting the CRM systems, forecasting models, and pipeline reporting that sit underneath sales, marketing, and customer success. I've done this through hypergrowth, acquisitions, and private equity ownership, which tends to mean the same core problem wearing different clothes: getting a go-to-market team to trust its own numbers.

More recently I've been using Claude Code to build internal tools directly — dashboards, automations, small applications — without being a trained software engineer. It's changed how I think about what an operations leader can ship on their own, instead of waiting in an engineering queue.
